# Support

Ask usage questions and share ideas in [Discussions](https://github.com/marc2825/Blender_SmartClip/discussions). Report bugs you can reproduce in [Issues](https://github.com/marc2825/Blender_SmartClip/issues).

Security problems are not reported in public: see [SECURITY.md](SECURITY.md) for the private report form.

Before opening an issue, check the existing issues and the [troubleshooting notes](docs/details.en.md#troubleshooting) ([日本語](docs/details.md#困ったとき)). A report is easiest to act on when it includes your Blender, add-on, and OS versions, the Snap To and Snap Point Limit settings, steps that reproduce the problem in a simple scene, and any error shown in the system console.
