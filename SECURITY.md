# Security Policy

## Supported versions

Security fixes go into the latest release on [GitHub Releases](https://github.com/marc2825/Blender_SmartClip/releases/latest). Older versions are not updated; please update to the latest release first.

| Version | Supported |
|---|---|
| Latest 2.0.x | Yes |
| Older | No |

## Reporting a vulnerability

Please do not report security problems in public issues, discussions or pull requests.

Report them privately through GitHub: **Security** tab → **Report a vulnerability** ([open a private report](https://github.com/marc2825/Blender_SmartClip/security/advisories/new)). Only the maintainer sees the report.

A useful report includes:

- the add-on version, Blender version and OS
- what an attacker could do, and under which conditions (for example, a crafted `.blend` file or add-on setting)
- steps or a minimal file that reproduce it
- whether the problem is already public

Do not include personal data, passwords or other secrets you do not need to.

## What happens next

This is a project maintained by one person in their spare time, so there are no guaranteed response times. The maintainer will:

1. confirm that the report was received,
2. investigate it and keep you informed in the private report,
3. if it is confirmed, publish a fixed release and a GitHub security advisory, crediting you unless you prefer otherwise.

Please keep the details private until a fix is released.

## 日本語

脆弱性やセキュリティ上の問題は、公開の Issue・Discussions・プルリクエストに書かず、GitHub の **Security** タブ → **Report a vulnerability**（[非公開で報告する](https://github.com/marc2825/Blender_SmartClip/security/advisories/new)）から非公開で報告してください。報告はメンテナーだけが見られます。

アドオン・Blender・OS のバージョン、起こり得ること（悪意のある `.blend` ファイルなど、どんな条件で何ができるか）、再現手順か最小限のファイルを書いてください。修正版の公開までは詳細を公開しないでください。個人で運営しているため、返答の期限はお約束できません。修正は最新版にのみ行います。
