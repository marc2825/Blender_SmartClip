# 操作ガイド

README の[インストールと使い方](../README.ja.md#インストールと使い方)と[移動中のキー操作](../README.ja.md#移動中のキー操作)を詳しく書いたものです。項目名は日本語表示での名前で、初出に英語表示での名前を添えています。

## エクステンションか従来形式か

2.1.0 から、各リリースには中身が同じ 2 つの ZIP があります。

| ZIP | Blender | 入り方 |
|---|---|---|
| `snaxis-vX.Y.Z-extension.zip` | 4.2 以降 | エクステンション（ディスクから入れた場合のモジュール名は `bl_ext.user_default.snaxis`） |
| `snaxis-vX.Y.Z.zip` | 4.0 以降 | 従来形式のアドオン（モジュール名 `smart_clipping`） |

Blender 4.2 以降ではエクステンションを使ってください。どちらも **プリファレンス → アドオン → ディスクからインストール**（Install from Disk）で入れます（4.2 以降は ZIP を Blender にドラッグしても入ります）。ZIP は展開しません。

**有効にできるのは一方だけ。** 両方とも同じツール、パネル、シーンの設定、ショートカットを登録するため、同時には有効にできません。後から有効にしようとした側は「Snaxis is already enabled as …」（有効になっている側の名前つき）で止まり、先に有効だった側はそのまま動きます。2.1.0 より前の版はこの確認をしないので、エクステンションを入れる前に、古い従来形式のアドオンを更新するか削除してください。2.1.0 のエクステンション（名前は Smart Clipping、ID は `smart_clipping`）も別のコピーとして扱われるため、`snaxis` のエクステンションを入れる前に削除してください。

**従来形式からエクステンションへ移るとき:**

1. アドオンの設定（スナップのしかた、スナップ距離、スナップ点の上限、色、候補の探し方、ショートカットを使う）と、変更したショートカットのキーを控えておきます。Blender はこれらをアドオンごとに保存するため引き継がれず、エクステンションは初期値から始まります。
2. **プリファレンス → アドオン** で従来形式のアドオン（一覧での名前は Snaxis、2.1.0 までは Smart Clipping）をオフにし、削除します。
3. エクステンションの ZIP を入れて有効にし、設定とキーを設定し直します。

スナップ先とそのコレクション、座標合わせは `.blend` にシーンごとに保存されるため、そのまま引き継がれます。逆向きに戻すときも同じ手順です。

## 操作

| 操作 | 動作 |
|---|---|
| `Shift+G` / パネルか「オブジェクト」「メッシュ」メニュー > トランスフォームの **ガイド付きで移動**（Move with Guides） | 移動を始める |
| 左クリック / `Enter` | 確定 |
| 右クリック / `Esc` | 取り消して元の位置に戻す |
| `Ctrl` を押し続ける | スナップせずに動かす（「徐々に引き寄せる」のときは、ぴったり合わせる） |
| `X` / `Y` / `Z` | その軸に沿ってだけ動かす |
| `Shift+X` / `Shift+Y` / `Shift+Z` | その軸を除いた面の上でだけ動かす |
| `A` | 座標合わせを切り替える: オフ → X → Y → Z → オフ |
| `S` | スナップ先を、スナップできるものがある次の選択肢に切り替える |
| `PageUp` / `PageDown`、または `Alt`＋ホイール | スナップ距離を広げる / 狭める（1 回ごとに 4 分の 1 ずつ、1〜1000 px） |
| 中ボタン / ホイール | 移動を続けたままビューを回転・パン・ズーム |
| テンキー / `Home` | 移動を続けたまま視点を切り替える・ズーム・全体表示 |

移動中は、これらのキーがステータスバーに表示されます。

マウスとテンキーの操作は、キーマップで視点操作に割り当てられているものだけが移動中に働きます。`Ctrl+テンキー+`（選択の拡大）のような、視点以外を変えるショートカットは働きません。`Alt`＋ホイールはフレームの変更ではなくスナップ距離の変更になり、ホイールだけならこれまでどおりズームします。

軸と面の拘束は、同じキーをもう一度押すと解除できます。拘束はワールド座標の軸に対して働き、拘束中の軸はテーマの軸の色の線で表示されます。スナップした位置も、拘束した軸や面の上に合わせます。頂点が軸や面の上にないときは、その上でいちばん近い位置（頂点の投影）に動き、「投影」と表示します。

`A`・`S` とスナップ距離のキーで変えた設定は、確定すると残り、取り消すと元に戻ります。動かさずに確定した場合も設定は残り、パネルで変えたときと同じく 1 回の操作として記録されます（オブジェクトモードでは元に戻す（`Ctrl+Z`）で戻せます）。何も変えずに確定した場合は記録しません。

## 移動中の表示

| 場所 | 内容 |
|---|---|
| スナップ点の横 | スナップしているかどうかと、何にスナップしているか（例:「スナップ中 Cube の頂点」）。「徐々に引き寄せる」では「引き寄せ中」と残りの距離。拘束や位置のロックで頂点まで届かないときは「投影」と、頂点までの距離 |
| スナップ点のマーカー | 引き寄せているだけのときと「投影」のときは中抜き、スナップすると塗りつぶし。形は種類を表します: 円は頂点、四角はバウンディングボックスの点（[スナップ点の上限](#スナップ点の上限)）、ひし形は座標合わせの位置 |
| 動かしている点の横 | 動かした距離（シーンの単位で。シーン > 単位の単位系・単位の倍率・長さに従います）と、拘束している軸や面 |
| 動かしている点を囲む点線の円 | スナップ距離。円の内側の頂点にスナップします。スナップしない間は表示しません |
| ビューの左下 | 現在のスナップ先と座標合わせ（変えたときはスナップ距離も）、および注意: スナップ先がないこと（理由と対処）、拘束で座標合わせが止まっていること、スナップ点の上限に達したこと |

色はテーマとガイドの色・スナップ時の色から取り、大きさはインターフェイスの拡大率に合わせます。

## スナップのしかた（Snap Behavior）

| スナップのしかた | スナップ距離の内側にスナップ点が入ったとき | `Ctrl` を押している間 |
|---|---|---|
| ぴったり合わせる（Snap Exactly、初期値） | 動かしている点をスナップ点にぴったり合わせる | スナップしない |
| 徐々に引き寄せる（Gradual Pull） | 近いほど強く引き寄せる（1.3 までの動き） | ぴったり合わせる |

## 動かすものとスナップさせる点

| モード | 動かすもの | スナップさせる点 |
|---|---|---|
| オブジェクトモード | 選択中のオブジェクトすべて（スナップ先が「選択したオブジェクト」のときはアクティブだけ） | アクティブオブジェクトの原点 |
| 編集モード | 編集中のメッシュの選択頂点 | 選択頂点の中心 |

確定したあとは、**最後の操作を調整**（Adjust Last Operation）パネルの **オフセット**（Offset）で移動量を数値で直せます。

## スナップ先（Snap To）

| スナップ先 | スナップする対象 |
|---|---|
| 同じメッシュ（Same Mesh） | 編集中のメッシュ（複数同時に編集しているときはそのすべて）。編集モードで、同じメッシュの別の頂点に合わせるときに使います |
| 選択したオブジェクト（Selected Objects） | 選択中のメッシュ。オブジェクトモードではアクティブ以外、編集モードでは編集中のメッシュの残りの頂点も含みます |
| 可視オブジェクト（Visible Objects、初期値） | 表示中のすべてのメッシュ |
| コレクション（Collection） | 指定したコレクションと、その子コレクションにある表示中のメッシュ |

移動中の `S` は、スナップできるものがないものを飛ばします。オブジェクトモードの「同じメッシュ」、オブジェクトモードでほかにメッシュを選択していないときの「選択したオブジェクト」、コレクションを指定していないときの「コレクション」です。切り替えるとスナップ点を集め直すので、大きなシーンでは少し時間がかかります。

## 座標合わせ（Align Only）

パネルの **座標合わせ** で X、Y、Z のどれかをオンにすると（移動中は `A`）、頂点に重ねる代わりに、近くの頂点とその軸の座標だけをそろえます。たとえば Z をオンにしたとき、z 座標が 1 の頂点があれば、XY の位置はそのままで z = 1 にそろえる候補になります。そろえる元の頂点までは点線で表示されます。

- パネルで複数の軸をオンにしても、そろえるのは一度に 1 軸だけです。`A` は 1 軸ずつ切り替えます。
- そろえた後の位置が、画面上でスナップ距離以内に入る値だけが候補になります。
- トップビューの Z のように、視線とほぼ平行な軸は対象外です。
- オンにした軸がどれも拘束で動かせないとき（X をオンにして Y に拘束したときなど）は、座標合わせが止まり、スナップせずに動きます。ビューの左下にその旨が表示されます。

## 設定

作業ごとに変える設定はサイドバーのパネル（**ツール** タブ）に、それ以外はサブパネル **上限と表示** とアドオンの設定（**プリファレンス → アドオン → Snaxis**）にあります。

| 項目 | 場所 | 初期値 | 内容 |
|---|---|---|---|
| パネル見出しのチェックボックス | パネル | オン | このシーンで Snaxis を使う。オフのシーンでは、ショートカットのキー（初期設定は `Shift+G`）が Blender 本来の機能として働く |
| スナップ先 | パネル | 可視オブジェクト | スナップする対象（[スナップ先](#スナップ先snap-to)） |
| 座標合わせ | パネル | オフ | 頂点に重ねる代わりに座標だけそろえる（[座標合わせ](#座標合わせalign-only)） |
| スナップ距離（Snap Distance） | パネル、アドオンの設定 | 30 px | スナップするまでの、動かしている点とスナップ点の画面上の距離。インターフェイスの拡大率 1 のときの値で、拡大率 2 では輪が 2 倍になります。移動中は `PageUp` / `PageDown` か `Alt`＋ホイールで変えられます |
| スナップのしかた | 上限と表示、アドオンの設定 | ぴったり合わせる | [スナップのしかた](#スナップのしかたsnap-behavior) |
| スナップ点の上限（Snap Point Limit） | 上限と表示、アドオンの設定 | 50,000 | 移動を始めるときに集めるスナップ点の上限（[スナップ点の上限](#スナップ点の上限)） |
| ガイドの色 / スナップ時の色（Guide Color / Snap Color） | 上限と表示、アドオンの設定 | マゼンタ / シアン | スナップ前 / スナップ中のガイド線とマーカーの色 |
| 候補の探し方（Snap Search） | アドオンの設定（詳細設定） | 画面上の格子 | 候補を探す方法（[候補の探し方](#候補の探し方snap-search)） |

スナップ先と座標合わせはシーンごとに `.blend` に保存され、ほかはアドオンの設定として保存されます。

アドオンの設定の **ショートカット**: 初期設定の `Shift+G` は、オブジェクトモードでは「グループで選択」、編集モードでは「類似選択」の代わりに使われ、そのことがキーの下に表示されます（キーを変えた場合は、そのキーで代わりに使われる機能）。この 2 つはメニューの「選択」からも使えます。**ショートカットを使う** でオン・オフを切り替えられます。オフにした状態は Blender を起動し直しても残ります。オブジェクトモードと編集モードのキーはここ（またはプリファレンスのキーマップ）で変えられ、**ショートカットを初期状態に戻す** で `Shift+G` に戻してオンにします。

## 表示言語

パネル、アドオンの設定、ツールチップ、ステータスバー、ビュー上の表示、メッセージは英語と日本語に対応しています。**プリファレンス → インターフェイス → 翻訳** の言語と、インターフェイス・ツールチップ・報告の各スイッチに従います。

## スナップ先の作り方

スナップ先は移動を始めた時点と、`S` でスナップ先を切り替えたときに作ります。それ以外は移動中に作り直しません。

### 対象になる形状

- スナップ先に含まれるメッシュの頂点です。カーブやテキストなど、メッシュ以外のオブジェクトは対象になりません。
- 形状はモディファイアを適用した後のものです。
- 編集モードのオブジェクトと、そのメッシュを共有しているオブジェクトは、モディファイアを適用する前の編集中のメッシュを使います。動かしている頂点を除くには頂点の番号が必要で、モディファイアを適用した形状では対応が取れないためです。

### 動かしているものは除く

動かしているものは、スナップ先になりません。

- オブジェクトモード: 動かすオブジェクトとその子
- 編集モード: 動かしている頂点（同じメッシュの他の頂点は、スナップ先に含まれていれば対象になります）。メッシュを共有しているオブジェクトからも除きます。

動かしている頂点は数に入れないので、スナップ点の上限を使いません。

このため、オブジェクトモードで「同じメッシュ」を選ぶとスナップ先はありません。「選択したオブジェクト」ではアクティブオブジェクトだけが動き、ほかの選択中のオブジェクトがスナップ先になります。

### スナップ点の上限

スナップ点の上限は、スナップ先として登録する点の総数の上限です。画面に映っているオブジェクトを先に、その中では動かすものに近い順に登録します。

1. 上限に収まるオブジェクトは、すべての頂点を登録します。
2. 上限をまたいだオブジェクトは、バウンディングボックスの角と原点（9 点）に、頂点を無作為に間引いたものを加えて登録します。
3. それより遠いオブジェクトは、角と原点だけを登録します。このために、上限の 1 割までを残しておきます。
4. 上限に達した後のオブジェクトは対象外です。

上限に達した移動のあとは、パネルに「スナップ点が上限に達しました」と、簡略化（間引き、または角と原点だけ）したオブジェクトと対象外にしたオブジェクトの数が表示されます。移動中は、ビューの左下にその旨が表示されます。

上限が抑えるのは登録する点の数です。移動を始めるとき（と `S` で切り替えたとき）は、上限に関係なく、スナップ先のメッシュの頂点をモディファイア適用後の形状からいったんすべて読み込みます。計測では、評価後 1,600 万頂点のメッシュで約 0.7〜0.8 秒、そのために増えるメモリは約 430 MB（シーン自体が使う量の 2 割ほど）で、どちらも頂点数にほぼ比例しました（Blender 4.0.2 / 5.2.4、[計測結果](DEVELOPMENT.md#large-meshes)）。

- 通常は初期値の 50,000 のままで十分です。
- 上限を 100 万に上げても、移動を始めるときの時間は少し増えるだけです（400 万頂点で約 0.2 秒 → 約 0.3 秒）。ただし、マウスを動かすたびの処理は登録した点が多いほど重くなります（[候補の探し方](#候補の探し方snap-search)）。
- 数千万頂点のメッシュがあるシーンで開始が遅いと感じるときは、スナップ先を「選択したオブジェクト」や「コレクション」にして、重いメッシュを対象から外してください。

## 候補の選び方

候補になるのは、動かしている点を画面に投影した位置からスナップ距離以内にある頂点です。マウスカーソルの位置ではありません。条件に合う頂点はすべて調べるので、頂点が密集していても見落としはありません。

候補が複数あるときは、画面上で近いものを選びます。画面上で 2 ピクセル以内に重なっているものどうしは、3D 空間で動かしている点に近いほうを選びます。シーンの縮尺やズームによって選ばれ方が変わることはありません。

動かしている点は次のとおりです。

- オブジェクトモード: アクティブオブジェクトの原点。アクティブが動かないときは、動かすオブジェクトの原点の平均
- 編集モード: 選択頂点の中心

3D 空間で探す範囲は、動かしている点の奥行きで画面の半分にあたる大きさです。シーンの単位がミリでもキロでも、画面上の見え方に対して同じように候補が見つかります。

### 候補の探し方（Snap Search）

アドオンの設定の **詳細設定** にある **候補の探し方** で、候補を探す方法を選べます。どちらを選んでも、見つかる候補と選ばれる候補は同じです。違うのは速さだけです。

| 候補の探し方 | 仕組み |
|---|---|
| 画面上の格子（Screen-space Grid、初期値） | スナップ先の点をすべて画面に投影し、画面上の格子に振り分けておきます。マウスを動かすたびに、動かしている点の周りの格子だけを調べます。視点を変えると、次にマウスを動かしたときに投影し直します |
| 3D KD-tree（実験的） | 移動を始めるときに、スナップ先の点から 3D の KD-tree を作ります。マウスを動かすたびに、画面上でスナップ距離以内に見える範囲（視点から伸びる円錐）にある点だけを KD-tree で取り出し、画面に投影して調べます。視点を変えても作り直しません |

計測では、ほとんどの場面で画面上の格子のほうが速くなりました。点が 10 万個のとき、マウスを動かすごとの処理は格子が約 0.2 ミリ秒、KD-tree が約 4 ミリ秒です。動かしている点の周りに点が密集していると KD-tree は大幅に遅くなり、10 万個が密集した場面では 1 回に約 0.5 秒かかりました。移動を始めるときにも時間がかかります（点 50 万個で約 1.2 秒）。通常は初期値のまま使ってください。計測結果は[開発者向け資料](DEVELOPMENT.md#grid-vs-kd-tree)にあります。

## 移動の扱い

- 親と子を両方選択しても、子が二重に動くことはありません。
- 位置をロック（Lock Location）した軸は動きません。オブジェクトのコンストレイント（位置制限など）も働きます。そのためにスナップ点まで届かないときは、届く範囲でいちばん近い位置に動き、「投影」と表示します。
- 移動中にビューを回転・パン・ズームしても、動かしている位置は飛びません。

## 困ったとき

### アドオンが一覧に出ない

- Releases の ZIP を入れたか確かめてください。Blender 4.0 / 4.1 では `-extension` の付かないもの（中に `smart_clipping/__init__.py` があるもの）を使います。エクステンションの ZIP は Blender 4.2 以降が必要です。
- Blender が 4.0 以降か確かめてください。
- 1.1.x 以前から更新した場合は、旧版（モジュール名 `src`）を削除してください。

原因がわからないときは、システムコンソール（Windows では ウィンドウ > システムコンソール切り替え）のエラーを見てください。

### 「Snaxis is already enabled as …」と出る

エクステンションと従来形式の両方が入っていて、もう一方が有効になっています。先にそちらをオフにしてください。[エクステンションか従来形式か](#エクステンションか従来形式か)を参照してください。

### 更新したあと有効にできない

2.0.0 を 1.x の上にインストールし、Blender を再起動せずにオフ・オンすると、`ImportError` が出ることがあります。2.0.1 以降を入れるか、Blender を再起動してください。

### Shift+G で移動が始まらない

- パネルの **ガイド付きで移動** にマウスを重ねてください。使えないときは、理由がツールチップに表示されます。
- パネル見出しのチェックボックスがオンか確かめてください。
- オブジェクトモードかメッシュの編集モードで、アクティブオブジェクトがあるか確かめてください。
- ショートカットをオフにしたり変えたりした場合は、アドオンの設定の **ショートカットを初期状態に戻す** で `Shift+G` に戻せます。

### 候補が出ない

- スナップ先がないときは、ビューの左下にその旨と理由が表示されます。
- スナップ先と、「コレクション」ならコレクションの指定を確かめてください。移動中は `S` で切り替えられます。
- 動かしているもの自体は候補になりません（[動かしているものは除く](#動かしているものは除く)）。
- 候補は、点線の円で示す動かしている点からの距離で選びます。カーソルが頂点の上にあっても、点が離れていれば見つかりません。点を候補に近づけるか、スナップ距離を大きくしてください。
- `Ctrl` を押している間（ぴったり合わせるのとき）と、拘束で座標合わせが止まっているときは、スナップしません。

### 移動の開始に時間がかかる

大きなシーンでは、スナップ点の上限を下げるか、スナップ先を「コレクション」にして対象を絞ってください。
