# 操作ガイド

README の[使い方](../README.md#使い方)を詳しく書いたものです。

## 操作

| 操作 | 動作 |
|---|---|
| `Shift+G` / パネルの **Smart Clipping Move** | 移動を始める |
| 左クリック / `Enter` | 確定 |
| `Esc` | 取り消して元の位置に戻す |
| 右ボタンを押し続ける | 候補にぴったり合わせる（Hard Snap） |
| `X` / `Y` / `Z` | その軸に沿ってだけ動かす |
| `Shift+X` / `Shift+Y` / `Shift+Z` | その軸を除いた面の上でだけ動かす |
| 中ボタン / ホイール | 移動を続けたままビューを回転・パン・ズーム |

軸と面の拘束は、同じキーをもう一度押すと解除できます。拘束はワールド座標の軸に対して働き、拘束中の軸は X が赤、Y が緑、Z が青の線で表示されます。スナップした位置も、拘束した軸や面の上に合わせます。

候補に近づくと、近いほど強く候補へ引き寄せられます（Soft Snap）。向かっている候補のオブジェクト名と距離は、ガイド線と画面左下の表示で確かめられます。

## 動かすものとスナップさせる点

| モード | 動かすもの | スナップさせる点 |
|---|---|---|
| オブジェクトモード | 選択中のオブジェクトすべて（Target Scope が Selected のときはアクティブだけ） | アクティブオブジェクトの原点 |
| 編集モード | 編集中のメッシュの選択頂点 | 選択頂点の中心 |

確定したあとは、**Adjust Last Operation** パネルの **Offset** で移動量を数値で直せます。

## Target Scope

| Target Scope | スナップ先 |
|---|---|
| Self Only | 編集中のメッシュ自身。編集モードで、同じメッシュの別の頂点に合わせるときに使います |
| Selected | アクティブ以外の選択中のメッシュ |
| All Visible（初期値） | 表示中のすべてのメッシュ |
| Manual Collection | 指定したコレクションと、その子コレクションのメッシュ |

## Axis Align

パネルの **Axis Align** で X、Y、Z のどれかをオンにすると、頂点の位置ではなく、その軸の座標値にそろえます。たとえば Z をオンにしたとき、z 座標が 1 の頂点があれば、XY の位置はそのままで z = 1 にそろえる候補になります。そろえる元の頂点までは点線で表示されます。

- 複数の軸をオンにしても、そろえるのは一度に 1 軸だけです。
- そろえた後の位置が、画面上で Snap Threshold 以内に入る値だけが候補になります。
- トップビューの Z のように、視線とほぼ平行な軸は対象外です。

## 設定

**Preferences → Add-ons → Smart Clipping** で変更できます。

| 項目 | 初期値 | 内容 |
|---|---|---|
| Snap Threshold (px) | 30 | 候補にする画面上の距離 |
| Max Vertex Budget | 50,000 | スナップ先として登録する頂点数の上限（[頂点数の上限](#頂点数の上限)） |
| Guide Color / Hard Snap Color | マゼンタ / シアン | ガイド線と表示の色（Hard Snap 中は後者） |

同じ画面の **Add Default Hotkeys** と **Clear Hotkeys** で、`Shift+G` の割り当てを戻したり外したりできます。

## スナップ先の作り方

スナップ先は移動を始めた時点で作り、移動中は作り直しません。

### 対象になる形状

- Target Scope の範囲にあるメッシュの頂点です。カーブやテキストなど、メッシュ以外のオブジェクトは対象になりません。
- 形状はモディファイアを適用した後のものです。
- 編集モードのオブジェクトだけは、編集中のメッシュを使います。

### 動かしているものは除く

動かしているものは、スナップ先になりません。

- オブジェクトモード: 動かすオブジェクトとその子
- 編集モード: 動かしている頂点（同じメッシュの他の頂点は、Target Scope に含まれていれば対象になります）

このため、オブジェクトモードで Self Only を選ぶとスナップ先はありません。Selected ではアクティブオブジェクトだけが動き、ほかの選択中のオブジェクトがスナップ先になります。

### 頂点数の上限

登録する頂点の数は Max Vertex Budget までです。動かすものに近いオブジェクトから順に登録します。

1. 上限に収まるオブジェクトは、すべての頂点を登録します。
2. 上限をまたいだオブジェクトは、残りの数に収まるように頂点を間引きます。
3. それより遠いオブジェクトは、バウンディングボックスの角と原点だけを登録します。

登録した頂点数と、間引いたオブジェクトとボックスだけにしたオブジェクトの数は、パネルの Performance 欄に表示されます。

## 候補の選び方

候補になるのは、動かしている点を画面に投影した位置から Snap Threshold 以内にある頂点です。マウスカーソルの位置ではありません。

動かしている点は次のとおりです。

- オブジェクトモード: アクティブオブジェクトの原点。アクティブが動かないときは、動かすオブジェクトの原点の平均
- 編集モード: 選択頂点の中心

3D 空間で探す範囲は、動かしている点の奥行きで画面の半分にあたる大きさです。シーンの単位がミリでもキロでも、画面上の見え方に対して同じように候補が見つかります。

## 移動の扱い

- 親と子を両方選択しても、子が二重に動くことはありません。
- Lock Location でロックした軸は動きません。
- 移動中にビューを回転・パン・ズームしても、動かしている位置は飛びません。

## 困ったとき

### アドオンが一覧に出ない

- Releases の ZIP（中に `smart_clipping/__init__.py` があるもの）を入れたか確かめてください。
- Blender が 4.0 以降か確かめてください。
- 1.1.x 以前から更新した場合は、旧版（モジュール名 `src`）を削除してください。

原因がわからないときは、システムコンソール（Windows では Window > Toggle System Console）のエラーを見てください。

### Shift+G で移動が始まらない

- パネルの Enable Smart Clipping がオンか確かめてください。
- オブジェクトモードかメッシュの編集モードで、アクティブオブジェクトがあるか確かめてください。
- 割り当てを外してしまった場合は、アドオン設定の Add Default Hotkeys で戻せます。

### 候補が出ない

- Target Scope と、Manual Collection ならコレクションの指定を確かめてください。
- 動かしているもの自体は候補になりません（[動かしているものは除く](#動かしているものは除く)）。
- 候補は動かしている点からの距離で選びます。カーソルが頂点の上にあっても、点が離れていれば見つかりません。点を候補に近づけるか、Snap Threshold を大きくしてください。

### 移動の開始に時間がかかる

大きなシーンでは、Max Vertex Budget を下げるか、Manual Collection で対象を絞ってください。
