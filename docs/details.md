# 動作の詳細と困ったとき

README の[使い方](../README.md#使い方)を補う資料です。

## スナップ先の作り方

移動を始めた時点で、Target Scope の範囲にあるメッシュの頂点からスナップ先を作り、移動中は作り直しません。形状はモディファイアを適用した後のもので、編集モードのオブジェクトだけは編集中のメッシュを使います。カーブやテキストなど、メッシュ以外のオブジェクトはスナップ先になりません。

動かしているものはスナップ先から外します。オブジェクトモードでは選択中のオブジェクトとその子、編集モードでは動かしている頂点です。このため、オブジェクトモードで Self Only を選ぶと、スナップ先がなくなります。オブジェクトモードで Selected を選んだ場合も、選択中のオブジェクトはすべて動くため、スナップ先がなくなります。

登録する頂点の数は Max Vertex Budget までです。動かすものに近いオブジェクトから順に登録します。上限をまたいだオブジェクトは残りの数に収まるように頂点を間引き、それより遠いオブジェクトはバウンディングボックスの角と原点だけを登録します。登録した頂点数と、間引いたオブジェクトとボックスだけにしたオブジェクトの数は、パネルの Performance 欄に表示されます。

## 候補の選び方

候補になるのは、マウスカーソルではなく、動かしている点を画面に投影した位置から Snap Threshold 以内にある頂点です。動かしている点は、オブジェクトモードではアクティブオブジェクトの原点、編集モードでは選択頂点の中心です。アクティブオブジェクトが動かないときは、動かすオブジェクトの原点の平均を使います。

3D 空間で探す範囲は、動かしている点の奥行きで画面の半分にあたる大きさに合わせて変わります。シーンの単位がミリでもキロでも、画面上の見え方に対して同じように候補が見つかります。

## 移動の扱い

親と子を両方選択しても、子が二重に動くことはありません。Lock Location でロックした軸は動きません。移動中にビューを回転・パン・ズームしても、動かしている位置は飛びません。

## 困ったとき

アドオンが一覧に出ないときは、Releases の ZIP（中に `smart_clipping/__init__.py` があるもの）を入れたか、Blender が 4.0 以降かを確かめてください。1.1.x 以前から更新した場合は、旧版（モジュール名 `src`）を削除します。原因がわからないときは、システムコンソール（Windows では Window > Toggle System Console）のエラーを見てください。

`Shift+G` で移動が始まらないときは、パネルの Enable Smart Clipping がオンか、オブジェクトモードかメッシュの編集モードでアクティブオブジェクトがあるかを確かめてください。割り当てを外してしまった場合は、アドオン設定の Add Default Hotkeys で戻せます。

候補が出ないときは、Target Scope と、Manual Collection ならコレクションの指定を確かめてください。動かしているもの自体は候補になりません（[スナップ先の作り方](#スナップ先の作り方)）。候補は動かしている点からの距離で選ぶので、カーソルが候補の上にあっても点が離れていれば見つかりません。その場合は点を候補に近づけるか、Snap Threshold を大きくしてください。

大きなシーンで移動の開始に時間がかかるときは、Max Vertex Budget を下げるか、Manual Collection で対象を絞ってください。
