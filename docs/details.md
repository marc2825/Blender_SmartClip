# 動作の詳細と困ったとき

README の[使い方](../README.md#使い方)を補う資料です。

## スナップ先の作り方

スナップ先は移動を始めた時点で作り、移動中は作り直しません。

### 対象になる形状

- Target Scope の範囲にあるメッシュの頂点です。カーブやテキストなど、メッシュ以外のオブジェクトは対象になりません。
- 形状はモディファイアを適用した後のものです。
- 編集モードのオブジェクトだけは、編集中のメッシュを使います。

### 動かしているものは除く

動かしているものは、スナップ先になりません。

- オブジェクトモード: 動かすオブジェクトとその子
- 編集モード: 動かしている頂点（同じメッシュの他の頂点は、Target Scope に含まれていれば対象になります）

このため、オブジェクトモードで Self Only を選ぶとスナップ先はありません。Selected ではアクティブオブジェクトだけが動き、ほかの選択中のオブジェクトがスナップ先になります。

### 頂点数の上限

登録する頂点の数は Max Vertex Budget までです。動かすものに近いオブジェクトから順に登録します。

1. 上限に収まるオブジェクトは、すべての頂点を登録します。
2. 上限をまたいだオブジェクトは、残りの数に収まるように頂点を間引きます。
3. それより遠いオブジェクトは、バウンディングボックスの角と原点だけを登録します。

登録した頂点数と、間引いたオブジェクトとボックスだけにしたオブジェクトの数は、パネルの Performance 欄に表示されます。

## 候補の選び方

候補になるのは、動かしている点を画面に投影した位置から Snap Threshold 以内にある頂点です。マウスカーソルの位置ではありません。

動かしている点は次のとおりです。

- オブジェクトモード: アクティブオブジェクトの原点。アクティブが動かないときは、動かすオブジェクトの原点の平均
- 編集モード: 選択頂点の中心

3D 空間で探す範囲は、動かしている点の奥行きで画面の半分にあたる大きさです。シーンの単位がミリでもキロでも、画面上の見え方に対して同じように候補が見つかります。

## 移動の扱い

- 親と子を両方選択しても、子が二重に動くことはありません。
- Lock Location でロックした軸は動きません。
- 移動中にビューを回転・パン・ズームしても、動かしている位置は飛びません。

## 困ったとき

### アドオンが一覧に出ない

- Releases の ZIP（中に `smart_clipping/__init__.py` があるもの）を入れたか確かめてください。
- Blender が 4.0 以降か確かめてください。
- 1.1.x 以前から更新した場合は、旧版（モジュール名 `src`）を削除してください。

原因がわからないときは、システムコンソール（Windows では Window > Toggle System Console）のエラーを見てください。

### Shift+G で移動が始まらない

- パネルの Enable Smart Clipping がオンか確かめてください。
- オブジェクトモードかメッシュの編集モードで、アクティブオブジェクトがあるか確かめてください。
- 割り当てを外してしまった場合は、アドオン設定の Add Default Hotkeys で戻せます。

### 候補が出ない

- Target Scope と、Manual Collection ならコレクションの指定を確かめてください。
- 動かしているもの自体は候補になりません（[動かしているものは除く](#動かしているものは除く)）。
- 候補は動かしている点からの距離で選びます。カーソルが頂点の上にあっても、点が離れていれば見つかりません。点を候補に近づけるか、Snap Threshold を大きくしてください。

### 移動の開始に時間がかかる

大きなシーンでは、Max Vertex Budget を下げるか、Manual Collection で対象を絞ってください。
